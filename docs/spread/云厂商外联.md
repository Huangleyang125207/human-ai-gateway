## 二、阿里云百炼（钩子：我是你的获客渠道）

**渠道**：① 搜"阿里云创业者计划"官网入口提交申请（代金券）② 百炼控制台工单 ③ 百炼官方钉钉群/开发者社区找运营

**核心话术**（这是四家里最硬的商业逻辑，工单和邮件都用它开头）：

> 我的产品让每个新用户注册一个百炼 key 并自费充值——**我不是来要补贴的成本中心，是在给百炼带新注册付费用户的获客渠道**。你们给新用户发的免费额度本来就是获客预算，我在帮这笔预算花得更准。
>
> 请求：① 产品 7 天试用期的 token 成本支持（量级：百元级/月，封顶可控）② 或联合权益：经我的产品引导注册的新用户获得额外额度。回报：装机引导页内的注册教程持续为百炼导流 + 公开案例。

**注意**：创业者计划大额度档位通常要营业执照；先按个人开发者档申请，被卡主体时再评估个体工商户（那本来就是收费前要办的事）。

**话术**：

> 现有客户：服务器 + COS + CDN 都跑在腾讯云上（轻量服务器 + 对象存储分发装机包，月账单 [填实际数]）。产品内测中（小红书社群 141 人，Mac/Win 桌面应用）。
> 请求：创业者/开发者扶持代金券，cover 基础设施侧（带宽/存储/CDN 流量随内测增长）。回报：案例授权。

**注意**：腾讯的兴趣点会是让你接混元——模型侧不接（产品魂），基础设施侧的钱照拿。
