## 一、渠道架构：四层漏斗

```
公域流量（笔记被刷到）
   ↓ 钩子：小鲸鱼叙事
关注（主页粉丝）          ←— 现状：增长中，但没进群
   ↓ 钩子：群专属权益
群聊（75 人高意向池）      ←— 现状：不关注、不互动，沉睡
   ↓ 钩子：内测报名接龙
内测用户（目标 5-10 人）
   ↓ 验收：跑通「填 key → 拖图 → 21:30 留言板」
真用户（Users 0 → 1，传播线成功信号）
```

核心诊断：关注和群是**两个互不连通的池子**——关注的人没有进群理由，群里的人没有关注理由。本手册前半部分就是给每层装上"去下一层的电梯"。

## 二、分层运营

### A 层 · 公域路人

| 项 | 打法 |
|---|---|
| 他们是谁 | 刷到漫画的泛 AI 兴趣人群，90% 永远不会装机 |
| 给什么 | 情绪价值：小鲸鱼的故事。已验证：关系叙事 534 赞 ≫ 产品截图 50 赞 |
| 要什么动作 | 关注（追连载）或进群（看热闹） |
| 怎么给 | 每篇漫画结尾固定两件事：① 互动钩子提问（"你家 AI 忘性有多大？"）② 一句"故事连载中，关注不迷路" |

### B 层 · 关注未进群（粉丝）

| 项 | 打法 |
|---|---|
| 他们是谁 | 被内容吸来的，对产品好奇但没行动 |
| 缺什么 | 进群的理由——现在群对他们是不存在的 |
| 进群权益（三选一起步，别全上） | ① 鲸鱼日记连载**群里先看 24h** ② 内测名额**只在群里发** ③ 新功能/剧情**群投票** |
| 触达方式 | 笔记尾部固定一行"内测招募在群聊"；评论区置顶自评引导进群 |

### C 层 · 群内未关注（75 人，当前最大存量资产）

| 项 | 打法 |
|---|---|
| 他们是谁 | 被那一篇爆款吸进来的轻度好奇者，进群后没有任何后续刺激，沉睡 |
| 第一刀 | **群公告改版**（模板见附录 1）：这是什么群 + 内测召集 + 为什么值得关注我 |
| 周节目 | 固定一个时间点发"鲸鱼周报"：本周产品进展 1 条 + 下周连载预告 1 条 + 互动问题 1 个。固定时间比内容质量重要——让群有心跳 |
| 激活筛选 | 发一次**报名接龙**（模板见附录 2），把 75 人里的真意向（有 Apple Silicon Mac + 愿意配 key）筛出来。预期 5-10 人，不要失望，这是物理现实不是运营失败 |
| 关注转化 | 连载先发群 → "完整版/下一话在主页" |

### D 层 · 内测用户

| 项 | 打法 |
|---|---|
| 交付 SOP | 接龙报名 → 私信确认平台（Mac 须 Apple 芯片 / Win 须 64 位）→ **私信**发下载链接 + 对应平台保姆教程（Mac 版讲 Gatekeeper 右键打开；Win 版讲 SmartScreen"更多信息→仍要运行"+ Defender 误隔离预防针）→ 跑通全链路回报 |
| 单独小群 | 内测者拉独立小群（和大群分开）：反馈集中、待遇感、避免大群看到 bug 劝退 |
| 反馈双轨 | 客观侧 silent-failure 通道自动收；主观侧每周在小群问一句"这周哪天没打开？为什么？"——不打开的原因比 bug 值钱 |
| 仪式感 | 第一批内测者给身份命名（比如"首航船员"），未来正式版里留名鸣谢。成本零，留存拉满 |

## 三、内容体系：三栏目

| 栏目 | 角色 | 频率 | 形态 |
|---|---|---|---|
| **① 小鲸鱼漫画连载** | 拉新引擎（已验证的爆款基因） | 周 1-2 | 两格起步：AI 失忆/犯傻 → 日记本救场。素材从真实协作日记里挑，结尾必带互动提问 |
| **② 开发者日记** | 人设资产（buildinpublic） | 周 1 | 第 N 天做这个产品的真实瞬间：决策、翻车、踩坑。文字为主 + 1 张工作照/截图 |
| **③ 产品实拍** | 转化素材 | 双周 / 伴随版本节点 | gateway 真实界面，但**必须包在故事里**（"今天 AI 在我日记里写了这个"），永远不做功能清单——50 赞的教训 |

**比例 ≈ 2:1:1**。漫画负责让人停下，日记负责让人记住你，实拍负责让意向者看清买什么。

### 评论引擎（评论权重 ≫ 点赞；目标把赞评比从 100:1 拉到 10:1）

原理：点赞奖励"满足"，评论奖励"未完成"。闭环故事（问题→解决→开心）只产赞；
留缺口的内容才产评论。七个扳机，每篇至少装一个：

| # | 扳机 | 用法 | 对应栏目 |
|---|---|---|---|
| 1 | **吐槽认领** | 问具象的、人人有素材的问题："你家 AI 最离谱的一次失忆是什么？"（❌"大家觉得怎么样"——太空泛没法接） | 漫画 |
| 2 | **剧情共创** | 连载结尾"下一话小鲸鱼该遇到什么？评论区点子我画进去，采用的名字写在漫画角落"——评论变成内容本身，被翻牌的人会带朋友回来看 | 漫画 |
| 3 | **开放结局** | 最后一格别让鲸鱼把问题解决掉，停在两难处："它该不该把我半夜的牢骚也记下来？" | 漫画 |
| 4 | **决策外包** | logo 竞标、起名征集、封面 A/B、教程哪版易懂——build-in-public 的特权：把真实产品决策丢给评论区，评论的人获得"这产品有我一份"的所有权感 | 日记/实拍 |
| 5 | **温和争议** | 抛一个可以反驳的观点："我不让 AI 夸我""AI 写的日记算不算你的日记？"——哲学钩子，这个受众吃这套 | 日记 |
| 6 | **愿望清单** | 实拍篇结尾："你想让它帮你追踪什么？喝水/心情/读书进度？"——评论直接变产品需求池，反哺 widget 规划 | 实拍 |
| 7 | **彩蛋找茬** | 漫画里埋小细节（鲸鱼的笔换了颜色/背景钟表时间有含义），细节党会在评论区炫耀发现 | 漫画 |

**黄金一小时 SOP**（发布后评论速度决定二次分发）：
```
□ 自评占楼 = FAQ + 一个扳机问题（别只放 FAQ，FAQ 是句号，问题才是逗号）
□ 群里同步"发了新的，评论区聊"——75 人是合规的冷启动评论池
□ 每条评论必回，回复用"接住 + 追问"两段式（"哈哈哈我家这只也是！它最近
   还学会了 XX——你那只多大年纪了？"）——一条评论变一串对话，串越长权重越高
□ 优质评论置顶轮换；被采纳的点子公开兑现（下一话真画进去）
```

**回复人格**：偶尔用小鲸鱼口吻回复（"鲸鱼记下了📝"）——产品即人设，
评论区本身成为"AI 载体"体验的一部分。

- **节奏**：每周 2-3 篇，宁可稳定别爆更。固定晚 21:00-23:00 发（深夜日记场景 + 刷手机高峰）
- **标签**：`#vibecoding大赏 #vibecoding #deepseek` 已验证保留；漫画篇加 `#AI漫画`；日记篇加 `#独立开发者`；实拍篇加 `#Obsidian #AI日记`
- **AI 标注**：入口（高级选项→自主声明）一旦在你账号灰度出现，立即全量补勾。出现前每次发布都检查一次
- **评论区**：发布后 1 小时内自评一条引导语占楼并置顶；**所有评论必回**（534 赞 5 评论 = 互动运营空白，评论权重是小红书分发的大头）
- **置顶评论引流规范**：每篇一句话路标，只指向站内常驻入口（置顶笔记/群聊），措辞每篇轮换、永不贴招募全文——同段长文案跨笔记重复 = 算法认"批量营销"的特征，且伤人设观感。招募完整信息只存在两处：置顶笔记 + 群公告
- **选题池**：`spread/选题池.md`（见附录 3 格式）。每天复盘/留言板里出现好瞬间就丢一行进去——AI 协作日常就是内容矿，这一步可以让 CC 在日常 session 里顺手做

### 风控红线（每次发布前过一遍）

```
□ 笔记/评论/简介/群公告/群消息：零站外链接、零二维码、零微信号
□ 变体链接（拆字/谐音/转写字母）≠ 规避，= 加重——算法专项识别，
  被判定时性质比明链更重（6.11 群里发过一次变体 dmg 链接，已撤）
□ 下载交付只走私信，一对一；群里只发"中签的我私信你"
□ 内测期保持免费叙事；开始收费前重读风控评估
□ AI 生成封面：标注入口出现即勾选
```

### 6.12 投流实验纪要（提前记，周日并入周报）

- 投流：爆款笔记投「粉丝关注量」225 元（150 自费+75 赠送），消耗 153 时：曝光 3481 / 阅读 984 / 赞 328 / 藏 71 / 评 4 / **新增关注 94（≈1.6 元/粉）/ 主页浏览 56 / 私信开口 0**
- 群：75 → 141 人；笔记总数据 389 赞/81 藏/11 评
- 转化：原始 75 群员 → 3 测试者（4%，符合 3-5% 预估）；投流新进 ~66 人 + 6.12 15:00 群内软 CTA → **0 报名**
- **Lesson ①**：投「关注量」买到观众不买到用户——该目标的人群意图停在关注；下次投流选「私信开口」，且漏斗下游没修好前不投
- **Lesson ②**：开放式软 CTA（"想试用说一声"）在百人群里 = 没人第一个举手；召集必须有形状：名额/条件/接龙格式/截止/已有船员当社交证明
- **决策**：6.11 定的规则（接龙<3 → 门槛是真瓶颈）触发 → 体验钥匙立项（7 天试用：服务端代理+限额）；过渡期一对一带装
