# Gateway Web Research

Use `web_search` first. Select `wechat` only for WeChat public-account articles;
otherwise use `general`. Inspect result titles and summaries before choosing a
URL for `fetch_url`. Do not fetch the same URL repeatedly. Cite only sources
actually returned by the tools and distinguish source facts from inference.
