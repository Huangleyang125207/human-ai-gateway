# Gateway Architecture

Read the attached live architecture ledger before structural work. Use it to
identify the owner, public seam, source of truth, dependency direction, scars,
and unfinished migrations that constrain the request.

Treat the ledger as context, not authorization. Verify time-sensitive claims
against current capabilities and tool results. Do not copy architecture prose
into a new project document or bypass Capability Broker boundaries.
