## 一句话规矩（详见 brief「核心原则」）

- 你只设计 **① 交互（触屏手势）　② UI（布局 / 视觉 / 动效）**。
- 其余（功能 / 数据 / 行为 / 文案）= 桌面，**照搬不改**，CC 落地。
- 颜色 **只用 classic**（米黄 + 4 粉彩 + 金棕）。**不要朱砂 / oklch 夜色 / paper（纸与灯）那套**
  —— 那是另一套皮肤，不在本轮。classic 单一日间、无夜色。
- 这个包**不含后端 / 逻辑 / 构建代码**——那是 CC 的事，你不用看。

条目左滑删 / 长按拉进对话 / + 卡片弹出）+ 移动组件 CSS reference（基于 classic 色）。
